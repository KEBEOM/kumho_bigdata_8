# 상관분석·구조방정식 사용 안내 · v1.3

은수현 · 김정훈 · 김응범 | 2026-11-26

기존 설명서의 7개 분석에 상관관계와 구조방정식/CFA 메뉴를 추가했습니다. 교수자 구두 안내의 평가 범위를 고려한 확장입니다. 제공 설명서에는 구체적인 SEM 모형이 없으므로, 수업의 모든 모형을 구현했다고 주장하지 않습니다.

## 상관분석

1. 기본 36사례 자료 또는 자신의 엑셀/CSV를 선택합니다.
2. 분석 종류에서 **상관관계**를 선택하고 수치형 열 2~10개를 고릅니다.
3. 선형 관계는 Pearson, 순위의 단조 관계는 Spearman을 선택합니다.
4. 결측 처리 방식을 고르고 분석을 실행합니다. 쌍별 사례 수, 상관계수, 양측 p와 Holm 보정 p를 함께 봅니다.

쌍별 제외는 각 쌍에 값이 있는 행을 사용합니다. 공통 완전사례는 선택한 모든 열에 값이 있는 행만 사용합니다. 다른 열의 결측은 영향을 주지 않습니다. 무한대는 결측이며 숫자 아닌 값은 오류로 안내합니다. 유효 사례가 3개 미만이거나 한 열이 상수인 쌍은 계산하지 않습니다.

Pearson은 SciPy의 양측 검정을 사용하고, n>3에서 Fisher z 변환의 95% 신뢰구간을 제공합니다. n=3이면 신뢰구간을 비웁니다. Spearman은 평균 순위를 사용합니다. n≤7은 행 인덱스의 모든 순열, 8~500은 4,999회 Monte Carlo 순열(기본 시드 42), n>500은 SciPy 근사 검정입니다. 양측 순열검정은 |ρ|가 관측값 이상인 비율이며 Monte Carlo p=(초과 횟수+1)/(반복 수+1)입니다. 동률이 있어도 원자료 행 단위 순열을 사용합니다. Spearman CI는 제공하지 않습니다.

Holm 보정은 계산 가능한 고유 변수 쌍 전체에 적용합니다. 대각 p는 검정 대상이 아닙니다. 상관계수·원 p·보정 p·사례 수 행렬을 XLSX에 저장하며 행 변수 이름도 보존합니다. 독립 관측을 전제하며 상관을 인과관계로 해석하지 않습니다. 쌍별 결측 제외로 얻은 행렬을 그대로 SEM의 입력 공분산으로 사용하지 않습니다.

## 잠재변수 SEM/CFA

왼쪽에서 **구조방정식 예제로 연습**을 선택하면 기본 모형과 지표가 채워집니다. **분석 실행**을 누르면 됩니다. 기준 자료 상태에서 SEM 메뉴를 고를 때도 이 예제로 전환합니다. 업로드한 사용자 자료는 자동으로 바꾸지 않습니다.

예제는 생성 코드 `data/generate_sem_sample.py`로 만든 300사례·9지표 자료입니다. x1–x3는 학습지원(X), m1–m3는 학습몰입(M), y1–y3는 학습성과(Y)를 가정한 연속형 지표입니다. 실제 학생 자료나 검증된 설문척도가 아니며 교수자 36사례 기준 자료와 별도입니다.

| 모형 | 측정 관계 | 잠재변수 관계 |
|---|---|---|
| 2변수 구조모형 | X·Y 각각 3~6지표 | X → Y |
| 3변수 구조모형 | X·M·Y 각각 3~6지표 | X → M, M → Y, X → Y |
| 2요인 CFA | X·Y 각각 3~6지표 | 두 요인 간 상관 |
| 3요인 CFA | X·M·Y 각각 3~6지표 | 세 요인 간 상관 |

하나의 관측지표를 여러 요인에 중복 배정할 수 없습니다. 각 요인의 첫 번째 지표 부하량을 1로 고정하여 척도를 정합니다. 완전사례가 50개 이상이어야 실행됩니다. **50은 이 앱의 실행 제한이며 적절한 표본 크기의 보장이 아닙니다.** 표본 적정성은 모형·부하량·분포·분석 목적에 따라 판단해야 합니다.

semopy 2.3.11에서 연속형 자료의 MLW 목적함수를 SLSQP로 최적화합니다. 선택 지표의 완전사례를 사용하며 평균·절편은 추정하지 않습니다. 독립 관측과 다변량 정규성을 전제로 한 모형 기반 SE를 사용합니다. 순서형 전용 추정, 강건 SE/적합도, 다집단·다층, 교차부하, 잔차 상관, 평균구조는 제공하지 않습니다. 잠재 간접효과의 유의성·부트스트랩 CI도 제공하지 않습니다. 기존 매개효과 메뉴는 관측변수의 회귀 기반 분석이므로 SEM 메뉴와 구분합니다.

결과에는 표준화·비표준화 부하량, 구조경로, 분산·공분산, 내생 잠재변수 R²와 경로도를 표시합니다. **SE·z·p·95% CI는 비표준화 B에 대한 값**입니다. 고정 부하량에는 SE·p·CI를 표시하지 않습니다. 경로도에서는 CFA의 양방향 화살표가 잠재 상관, 구조모형의 단방향 화살표가 표준화 경로계수입니다. 관측지표와 요인 사이의 연결은 별도 부하량 표에서 확인합니다.

## 계산과 적합도 규약

공분산 S는 N 분모, 모형 공분산은 Σ, 관측변수 수는 p, 자유 모수 수는 k입니다.

- ML 불일치 F = log|Σ| + tr(Σ⁻¹S) − log|S| − p
- χ² = N·max(F, 0), df = p(p+1)/2 − k
- 독립 기준모형 χ²₀ = N·[Σ log(Sᵢᵢ) − log|S|], df₀ = p(p−1)/2
- CFI = 1 − (χ²−df)/(χ²₀−df₀)
- TLI = (χ²₀/df₀ − χ²/df)/(χ²₀/df₀ − 1)
- RMSEA = √[max(χ²/df−1, 0)/(N−1)]

CFI/TLI의 기준 분모가 0 이하이면 계산 불가로 표시합니다. **CFI·TLI는 원값을 사용해 0~1 밖일 수 있습니다.** RMSEA는 semopy의 N−1 규약이며, N 분모를 쓰는 도구와 소수점 아래 값이 다를 수 있습니다. 부하량과 p는 표준화 값에 대한 검정이 아닙니다. χ²의 p는 chi-square 생존함수, 모수의 양측 p는 2·norm.sf(|B/SE|), CI는 B±1.95996398454·SE입니다.

수렴하지 않거나 지표 공분산이 거의 특이한 경우, 정보행렬의 식별·수치 안정성에 문제가 있는 경우는 오류로 안내합니다. 분산 0 경계와 절댓값 1 초과 표준화 부하량은 부적절한 해 가능성으로 경고합니다. 경고가 없어도 모형 타당성을 보장하지 않습니다.

적합도를 합격/불합격으로 자동 판정하지 않습니다. 특히 세 잠재변수의 모든 관계를 포함한 기본 구조모형은 동일 측정모형의 상관된 3요인 CFA와 같은 공분산을 설명할 수 있습니다. 적합도만으로 방향이나 매개·인과관계를 입증할 수 없습니다.

## 시연 순서

기존 36사례에서 다중회귀 R²≈.9349를 확인한 뒤 상관관계의 score–pre_score 계수≈.9668과 쌍별 n을 설명합니다. 다음으로 구조방정식 예제로 전환해 가상 자료임을 밝히고 X/M/Y의 지표, 부하량, 경로도, 적합도를 보여 줍니다. 모형을 CFA로 바꾸었을 때 단방향 경로와 양방향 상관의 차이를 설명하고 결과표 XLSX/TXT를 내려받습니다.
