# Python 호환성 검증 결과

제출자: 은수현, 김정훈, 김응범

수정 목표는 특정 Python 3.12 버전을 반드시 설치하지 않아도 기존의 지원되는 Python으로 실행하는 것이다. requirements.txt를 범위 지정으로 바꾸고 Python별 호환 패키지를 선택하도록 했다.

## 실제 실행한 검사

환경: Linux x86_64, 64비트 CPython. 각각 독립된 가상환경에 패키지를 설치했다. 아래 표는 설명상 지원 목록이 아니라 실제 실행 결과다.

## 지원 범위와 한계

- 지원 대상: 64비트 CPython 3.9~3.14. Streamlit의 제외 조건에 따라 Python 3.9.7은 제외한다.
- 모든 패치 버전 및 모든 운영체제·CPU 조합을 검사한 것은 아니다. 실제 검사한 세부 버전은 위 표와 같다.
- Windows와 macOS용 실행 파일을 제공하지만 해당 운영체제의 실기기 실행은 이번 검증에 포함되지 않았다.
- 실제 스마트폰과 사용자 Wi-Fi 연결은 별도로 확인해야 한다.
- Python 3.8 이하, 3.15 이상, PyPy, 32비트 환경은 범위 밖이다. 미래의 모든 패키지 조합까지 보장하지 않는다.
- Python 자체가 설치되지 않았다면 먼저 지원 버전 중 하나를 설치해야 한다. 앱 실행기가 Python 자체를 설치하지는 않는다.

## 설치 방식

start.py는 표준 라이브러리로 Python을 확인하고 `.venv-py39`처럼 버전별 환경을 만든다. 시스템 패키지와 기존 `.venv`를 건드리지 않는다. 최초 실행 시 필요한 패키지를 설치하고, 이후에는 요구사항과 설치 상태를 확인해 환경을 재사용한다.

Windows: `run_windows.bat` / macOS: `run_mac.command` / macOS·Linux 터미널: `bash run_mac_linux.sh`. 같은 Wi-Fi 접속 시 `--lan`, 테스트 시 `--test`를 붙인다.

## 재현 자료

- `호환성검증.json`: Python별 버전, 패키지 목록, 테스트 출력.
- `locks/requirements-py39.txt` 등: 검증 환경의 정확한 패키지 조합. 다른 Python용 잠금 파일을 섞지 않는다.
- `자동검사결과.txt`: 환경별 실행 결과.
- `실행기검증.json`: 자동 설치·재실행·서버 시작 확인.
- `기준값_검산표.csv`: 기준표와 수치 비교.

참고한 공식 배포 메타데이터: https://pypi.org/project/streamlit/1.50.0/ 및 https://pypi.org/project/statsmodels/0.14.4/. Python별 실제 설치 가능성과 동작 여부는 위 실행 결과로 검증했다.
