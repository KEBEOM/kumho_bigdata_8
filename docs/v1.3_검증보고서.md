# v1.3 검증 기록

은수현 · 김정훈 · 김응범 | 2026-11-26 | Linux x86_64

상관관계 및 제한된 SEM/CFA를 추가했습니다. 기존 교수자 자료의 7개 분석은 유지했습니다. `python -m pytest -q tests`를 Python 3.9.25 / 3.10.22 / 3.11.18 / 3.12.14 / 3.13.5 / 3.14.10에서 각각 실행해 **82개씩, 총 492회 통과**했습니다. 정확한 패키지와 출력은 `v1.3_호환성검증.json` 및 `locks/`에 있습니다.

## 독립 검산

| 항목 | 대조 방법 | 결과 |
|---|---|---|
| Pearson | NumPy 상관행렬, t 분포 양측 p, Fisher z CI | 일치 |
| Holm 보정 | 정렬된 p에 남은 비교 수를 곱한 누적 최댓값 | 일치 |
| Spearman 소표본 | 5사례 전수 순열, 완전 역상관 p=2/120, 동률 사례 | 일치 |
| Spearman Monte Carlo | 동일 시드 재현, +1 보정, 501사례 근사 분기 | 통과 |
| 결측 처리 | pairwise/listwise의 다른 n, 무한대·상수 처리 | 통과 |
| XLSX 행렬 | 행 이름 충돌·수식형 문자열·원시 수치의 내보내기 | 통과 |
| CFA | 공개 lavaan Holzinger–Swineford 1939 예제 | 아래 표 참조 |
| 구조경로 | 별도 6,000사례 가상 자료의 .65/.55/.30 경로 | 표준화 계수 절대 오차 .045 이내 |
| 모형 안정성 | 4개 모형, 고정 부하량의 SE/p/CI 미표시, 잘못된 자료 | 통과 |
| 화면 흐름 | 9개 메뉴, 데이터·모형 변경 시 결과 초기화, 오류 안내 | 통과 |

공개 자료는 설치된 semopy의 `examples.holzinger39.get_data()`로 읽고, 기대값은 [lavaan 공식 CFA 예제](https://lavaan.ugent.be/tutorial/cfa.html)에서 대조했습니다. 새 모델의 모수를 앱 코드에 고정하지 않습니다.

| 지수 | 공개 예제(반올림) | 앱 계산 |
|---|---:|---:|
| χ² | 85.306 | 85.305522 |
| df | 24 | 24 |
| CFI | .931 | .930560 |
| TLI | .896 | .895839 |
| RMSEA | .092 | .092275 |

비표준화 부하량 6개도 공개된 값과 절대 오차 .001 이내에서 일치합니다. RMSEA는 앱에서 N−1 규약을 사용하므로 N 규약과 원시 수치가 약간 다릅니다. 이 검산은 모든 통계 모형에 대한 정확성 보장을 뜻하지 않습니다.

## 동봉 예제의 실제 출력

36사례 기준 자료에서 score–study_time Pearson r=.181764, p=.288707, Holm p=.577414이고 score–pre_score r=.966848입니다.

별도의 300사례 SEM 가상 예제 기본 모형은 χ²=21.194441, df=24, p=.627230, CFI=1.001925, TLI=1.002888, RMSEA=0입니다. 표준화 경로는 X→M=.673293, M→Y=.443888, X→Y=.399490입니다. CFI/TLI 원값은 1을 넘을 수 있으며 이상값으로 임의 교정하지 않습니다. 가상 표본의 추정계수는 생성 모수와 정확히 같지 않습니다.
