## 실제 확인한 동작

- 배포 앱에서 제목 **데이터 한눈에**와 기준 데이터 **36사례·14변수**가 표시됐다.
- 저장된 프로필·로그인 정보를 사용하지 않은 별도 브라우저에서도 로그인 화면 없이 앱이 열렸다.
- 기준 데이터로 다중회귀를 실행했다. 종속변수는 `score`, 설명변수는 `study_time`, `pre_score`였다.
- `결과표 엑셀` 버튼을 눌렀을 때 다운로드가 시작됐다. 이 클라우드 확인에서는 내려받은 파일을 다시 열어 검사하지는 않았다.
- `해석과 설정 TXT` 다운로드 버튼의 표시를 확인했다. 실제 TXT 다운로드 동작은 이번 확인 범위에 포함하지 않았다.

| 다중회귀 항목 | 화면에서 확인한 값 |
|---|---:|
| R² | 0.9349 |
| 수정 R² | 0.9310 |
| 절편 B | 15.757377 |
| study_time B | 0.072904 |
| pre_score B | 0.891204 |
| 설명변수별 VIF | 1.031973 |
| 제외 사례 수 | 0 |

R²는 제공 기준값과 표시 정밀도 안에서 일치했다. 다른 분석의 계산 검산 및 Python 3.9~3.14 환경 검사 기록은 기존 [호환성보고서](호환성보고서.md)와 검산표에 있다. 이번 배포 확인에서는 클라우드의 7개 분석 전체를 재검사하지 않았다.

## 별도 확인할 항목

- 실제 스마트폰에서 파일 선택, 좁은 화면의 표 스크롤, 분석 및 결과 파일 열기
- 사용자 Windows/macOS PC에서 로컬 설치·실행
- GitHub Actions의 원격 실행 결과
- 배포 서버의 정확한 Python 버전

실행 화면에서 확인하지 않은 항목을 완료했다고 기록하지 않는다.
