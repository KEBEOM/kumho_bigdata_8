# 데이터 한눈에 개발 기록

제출자: 은수현, 김정훈, 김응범

첨부 starter는 업로드와 기초통계만 구현되어 있었다. 이를 기반으로 회귀, ANOVA, 매개·조절 분석, 결과 저장과 입력 검증을 추가했다. 아래는 이번 제작에서 수행한 작업 기록이며, 실제 7주간 활동이나 팀원의 역할을 뜻하지 않는다. 앱 개발에는 생성형 AI의 도움을 받았다.

| 단계 | 작업 | 확인 |
|---|---|---|
| 요구사항 확인 | 학생용 설명서·starter·추가자료를 읽고 7개 분석과 제출 2종 확인 | 기준 데이터 36행·14열 |
| 구조 설계 | app.py와 analysis.py 분리 유지, data_io.py 추가 | 입력·화면·계산 책임 분리 |
| 통계 구현 | 기초통계, OLS, VIF, ANOVA, Tukey, 부트스트랩, 단순기울기 | 실제 데이터로 계산 |
| 입력 검증 | 결측, 문자 혼입, 중복 열/변수, 공선성, 부족한 표본·집단 검사 | 오류 입력 테스트 |
| 화면 구현 | 한국어 안내, 결과 다운로드, 그래프, 데이터 변경 시 이전 결과 제거 | AppTest 7메뉴 실행 |
| 검산 | 교수자 기준표와 비교, NumPy/SciPy 독립 대조 | 반올림 정밀도 내 일치 |
| 수정 | 테스트의 효과크기 열 이름 오타 수정 | 통계 계산식 변경 없음 |
| 수정 | pandas 빈칸 치환 시 암묵적 형변환 경고 처리 | 명시적 숫자 변환 유지 |
| 문서화 | 프롬프트, README, 환경 버전, 검산표, 제한점 기록 | ZIP 제출 구조 정리 |

## 핵심 설계 선택

- 최종 sample.xlsx는 모든 분석 변수가 있는 36사례 기준 자료이다. starter의 원래 12사례 자료는 별도 보관했다.
- 평균 대체 등 임의의 결측 대체를 하지 않는다. 기초통계는 열별, 모형은 선택한 열의 완전사례를 사용한다.
- 사용자 열 이름을 회귀식에 직접 넣지 않고 안전한 내부 이름으로 처리한다.
- 화면 해석은 계산값에 따른 한국어 규칙 기반 안내이며 실행 중 AI API를 호출하지 않는다.
- 검산 정답은 tests와 검산표에만 들어 있다. 실제 분석은 사용자가 고른 데이터로 계산한다.
- 이원분산분석 기본 Type II는 제공 기준표를 재현한다. Type III는 합 대비와 함께 선택할 수 있다.
- 매우 작은 p값을 정확히 0으로 오해하지 않도록 화면에는 < .001로 표시한다.

## 3분 발표 메모

1. 개발 목적: “엑셀 데이터를 불러와 통계분석과 해석을 한 화면에서 확인하는 교육용 웹앱을 만들었습니다. PC에서 실행하고 스마트폰 브라우저에서도 접근하도록 구성했습니다.”
2. 사용 시연: 기본 기준 데이터 → 다중회귀 → score를 Y, study_time과 pre_score를 X로 확인 → 분석 실행 → R²와 계수 표 확인 → 결과 엑셀 받기.
3. 계산 검산: “교수자 기준 데이터에서 다중회귀 R²는 약 0.9349이며, 기준표와 반올림 범위 안에서 일치합니다. 단순회귀와 분산분석 등 다른 분석도 검산했습니다.”
4. 오류 처리: “선택한 변수의 결측만 제외하고 사용·제외 사례 수를 알려 줍니다. 같은 변수 중복이나 부족한 집단 자료에는 한국어 안내를 보여 줍니다.”
5. 확장 기능: 매개 부트스트랩과 조절 단순기울기를 각각 시연한다. 상호작용·간접효과와 인과적 결론을 구분한다.
6. 한계: 반복측정, 강건 분석, 복잡한 매개모형은 지원하지 않는다. 실제 스마트폰 Wi-Fi 연결과 사용성은 제출자의 기기에서 마지막으로 확인한다.

## 제출자가 마지막으로 확인할 항목

- 두 ZIP의 이름을 실제 팀원 이름으로 맞춘다.
- 본인 PC에서 README를 따라 설치하고 기준 데이터 분석을 한 번 실행한다.
- 같은 Wi-Fi의 스마트폰으로 연결해 파일 선택·분석·표 스크롤·결과 다운로드를 확인한다.
- 실제 확인한 기기와 날짜, 문제 및 해결 방법을 추가 기록한다.
- 확인하지 않은 항목을 완료했다고 발표하지 않는다.

## v1.1 호환성 보완

- 조원 이름을 은수현, 김정훈, 김응범 순서로 앱과 문서, 제출 파일명에 반영했다.
- 단일 패키지 버전 고정을 범위 지정으로 바꾸고 Python 3.9~3.14의 6개 독립 환경에서 각각 59개 검사를 통과했다.
- 기준값 34개를 각 환경에서 다시 비교해 모두 반올림 정밀도 안에서 일치함을 확인했다.
- Python별 패키지 잠금 파일과 호환성보고서를 추가했다.
- start.py와 Windows/macOS/Linux 실행 파일을 추가해 버전 확인·전용 환경 준비·패키지 설치·실행을 연결했다.
- 기존 44개 통계·화면 검사에 실행기의 버전 판별·환경 격리·옵션 오류 검사 15개를 추가했다.
- Windows/macOS 실기기, 실제 스마트폰 접속은 이번 검증에 포함하지 않았다.
